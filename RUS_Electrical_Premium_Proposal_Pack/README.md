## Recommended workflow
1. Create a new private project/repository.
2. Copy the `assets` folder into `public/assets`.
3. Give OpenCode `opencode-master-prompt.md`.
4. Use GPT-5.6 Sol for the initial full build.
5. Run the build locally and check every claim against `COMPANY-DETAILS.md`.
6. Keep the proposal private until RUS Electrical approves the concept.
7. After the owner responds, confirm address, hours, email, secondary number, 24/7 service, compliance credentials and exact services.
